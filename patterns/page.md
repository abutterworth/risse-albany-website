# Page pattern

The initial page is intentionally small. Editable fields in content/site.json:

| Field | Purpose |
| --- | --- |
| title | Browser tab title |
| description | Search description |
| heading | Single main heading |
| intro | Introductory paragraph |
| notice | Honest prototype status |
| link_label | Descriptive call-to-action text |
| link_url | Absolute HTTPS destination |

Keep copy factual and readable. Use the existing template and CSS. Add a new documented pattern before introducing a new page type. Future services, events, and people should be structured content with shared templates rather than manually duplicated pages.

Example request: "Change the intro to [approved wording]. Preserve the prototype notice, run the checks, and open a pull request."
